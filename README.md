# Fundamentos de Programación

Trabajos y ejercicios de la materia **Fundamentos de Programación**, desarrollados en **Java** con Eclipse.

Instituto Tecnológico de Jiquilpan (TecNM) — Ingeniería en Sistemas Computacionales.

## Contenido

El código está organizado por temas dentro de la carpeta `src/`:

- **tema2** — Introducción: variables, tipos de datos, entrada/salida y conversiones.
- **tema3** — Estructuras de control: condicionales y ciclos (for, while, do-while).
- **tema4** — Arreglos y matrices: vectores, matrices y sus operaciones.
- **tema5** — Temas adicionales.
- **trabajos** — Trabajos y prácticas integradoras de la materia.

## Tecnologías

- Java
- Eclipse IDE
